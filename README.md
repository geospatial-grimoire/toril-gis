# Toril GIS: The Source for Forgotten Realms Geospatial Data

**Toril GIS** is an open, fan-made geospatial database of the *Forgotten Realms*, built on top of the legendary *Forgotten Realms Interactive Atlas*. It aims to become the most accurate and richly detailed digital map of *Toril* — including *Faerûn* and other continents — for exploration, cartography, and analysis in GIS environments.

This repository is part of the [**Geospatial Grimoire**](https://www.geospatial-grimoire.com/) initiative — where maps come alive and worlds take shape.

![A glimpse of the Toril GIS project in QGIS](resources/toril-gis-proj-behrmann.jpg)

---

## Project Status

**🛠️ Actively in development (2025)**
Toril GIS is being built layer by layer. Most datasets, styles, and exports are still in preparation, and new material is being added continuously. Expect structure and documentation to evolve as the foundation stabilizes.

> It may look empty, but there’s a lot happening behind the scenes — the datasets are being prepared and refined before release. GIS work is complex enough on its own, so we’d rather publish clean, well-structured data than rush unfinished layers.

---

## Quick Overview

- **Goal:** A full open-source GIS dataset of Toril, compatible with QGIS and PostGIS
- **Focus:** Accuracy, interoperability, and multilingual support
- **Current phase:** Core data modeling, coordinate systems, and foundational layers
- **Next steps:** Data population, symbology refinement, and export pipelines
